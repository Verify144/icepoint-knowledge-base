=== NETEASE ENCRYPTION UTILS ===
From: NetEaseEncryptionUtils (Java source, 37 blobs)

Case 1 (offline, signed=false):
- Offline mode: No server signature verification
- Used for local testing or air-gapped environments

Case 3 (3-layer, i==1 == NETEASE_PUBLIC_KEY):
- Three-layer encryption chain
- Layer 1: Client private key + Server public key (ECDH)
- Layer 2: Derived AES-256-CTR key + Salt
- Layer 3: Packet-level encryption with 8-byte integrity

Default (other cases):
- Throws exception: Invalid encryption chain

=== KEY TECHNICAL DETAILS ===
- Protocol Version: 818 (Bedrock 1.21.90) confirmed in icepointg79/protocol_version.go
- RakNet Protocol: 8 (NetEase fixed, upstream goes to 11)
- Heartbeat Interval: 5 seconds (not default 10 or 30)
- Dynamic Token: md5 mix with fixed magic string
- Batch Frame: Multiple packets + zlib compression
- Encryption: P-384 ECDH -> SHA256(salt||shared) -> AES-256-CTR
- Integrity: 8-byte verification suffix on every packet
- Packet IDs: 0xF2, 0xF3, 0xF5, 0xF8, 0xF9 (inventory/move/container operations)
