=== OVERVIEW ===
NetEase Minecraft login verification system supporting X19 and G79 dual protocols.
Includes account pool, guest auto-registration, proxy pool, stack defense.
Frontend: Vue 3 + Vite + TypeScript (verify-new-ui), default port 9191

=== FEATURES ===
1. NetEase login verification (X19 / G79 dual protocol)
2. Account pool (Cookie pool entry, fbToken random selection, 25min cache, ban auto-switch)
3. Guest full auto-registration (device creation -> SMS verification -> real-name -> pool entry)
4. vi prefix auto-rename (detect + rename integration, 6 chars length)
5. MO SMS verification (NetEase short number auto-parse)
6. Proxy pool (102 sources, HTTP only, CN priority, 30 min auto-refresh)
7. 4 server type classification (rental server / lobby / mountain / Tan Lobby)
8. Stack defense (breaker + retry backoff)
9. JSON persistence (auto-restore after restart, cookie never leaks)
10. Web UI + interactive CLI (double-click to start)

=== CORE MODULES ===

Network Engine (engine/):
- g79client / x19client / PE protocol encapsulation

Account Pool (internal/service/accountpool/):
- Cookie pool + fbToken + persistence + vi rename

Web UI (frontend/, only in verify-new-ui):

=== SECURITY DESIGN ===
- Cookies persisted server-side only, NEVER in API output
- Master token via environment VERIFY_TOKEN
- TLS skipped (NetEase PE endpoints use self-signed certs)
- Circuit breaker prevents NetEase anti-cheat ban
- fbToken random selection prevents single account abuse

=== API ENDPOINTS ===

Account Pool:
GET /api/pool/stats       Pool statistics
GET /api/pool/accounts    List accounts (cookie hidden)
POST /api/pool/accounts   Add account
DELETE /api/pool/accounts/:id Delete account
PUT /api/pool/accounts/:id/toggle Enable/disable

fbToken (server entry credential):
POST /api/pool/tokens       Create token
GET /api/pool/tokens        List tokens
DELETE /api/pool/tokens/:id Delete
POST /api/pool/tokens/:id/connect Server entry verification (core)

Guest Registration:
POST /api/mpay/guest       Create guest
POST /api/mpay/guest/batch Batch guest creation

Proxy Pool:
GET /api/proxy/pool       List proxies
POST /api/proxy/fetch     Manual fetch
GET /api/proxy/stats      Statistics

System:
GET /health               Health check
POST /api/admin/reload    Hot reload
POST /api/admin/restart   Restart process
