=== OVERVIEW ===
Unified building format parser for 37 formats.
Auto-detects format by magic number.
Plugin-style Parser interface.
Unified Structure representation.

=== ARCHITECTURE ===
icestructure/
├── Parser interface (Format/Magic/Extensions/Parse)
├── Structure (unified representation)
├── Bounds (bounding box)
├── BlockState (block with properties)
├── Entity (entities with NBT data)
├── Convert (format conversion)
└── Formats/ (37 implementations)

=== STRUCTURE REPRESENTATION ===
Structure:
- Format: string (format identifier)
- Bounds: Bounds {MinX, MinY, MinZ, MaxX, MaxY, MaxZ}
- Blocks: []BlockState
- Entities: []Entity
- Metadata: map[string]interface{}

BlockState:
- Name: string (block identifier)
- Properties: map[string]string (block properties)
- Position: [3]int (X, Y, Z)

Entity:
- Type: string
- Position: [3]float64
- Data: map[string]interface{} (NBT data via glacier-winter)

Bounds:
- MinX, MinY, MinZ, MaxX, MaxY, MaxZ int32

=== MAGIC NUMBER IDENTIFICATION ===
| Magic (hex/ascii) | Format |
|-------------------|--------|
| 0x1F 0x8B | gzip family: Schematic/SchemV1/SchemV2/Litematic/FuHongV5 |
| 0x50 0x4B 0x03 0x04 | MCWorld (ZIP) |
| 'B' 'D' 'I' '@' (0x42444940) | BDX (brotli compressed) |
| 'K' 'B' 'D' 'X' (0x4B424458) | KBDX |
| 'B' 'C' 'F' (0x424346) | BCF |
| 'H' '4' 'S' (0x483453) | SIBI |
| 0x0A | MCStructure (newline prefix) |
| '[' | FuHongV1/GangBan/RunAway (JSON array) |
| '{' | FuHongV2-V4/Construction/CovStructure (JSON object) |

=== PARSER INTERFACE ===
interface Parser {
    Format() string       // e.g., "Schematic", "Litematic"
    Magic() []byte        // detection magic bytes
    Extensions() []string // file extensions (e.g., [".schematic", ".litematic"])
    Parse(data []byte) (*Structure, error)
}

=== AUTO-DETECTION ===
ParseFile(data []byte) (*Structure, error):
1. Check magic bytes against all registered parsers
2. If unique match: call that parser's Parse()
3. If ambiguous: error (caller must specify format)
4. If no match: error (unknown format)

ParseByFormat(format string, data []byte):
- Directly calls specific parser

=== CONVERSION ===
Convert(source *Structure, targetFormat string) ([]byte, error):
1. Load source into Structure (unified)
2. Call target format's encoder
3. Returns encoded data in target format

=== USAGE EXAMPLE ===
import "github.com/Verify144/IceStructure"

func main() {
    data := readFile("building.litematic")
    
    // Auto-detect
    s, err := icestructure.ParseFile(data)
    if err != nil { panic(err) }
    fmt.Printf("Format: %s, Blocks: %d\n", s.Format, s.Metadata["BlockCount"])
    
    // Specify format
    s, err = icestructure.ParseByFormat(icestructure.FormatBDX, data)
    
    // Convert
    out, err := icestructure.Convert(s, icestructure.FormatSchematic)
}
