=== OVERVIEW ===
Bidirectional block mapping between Minecraft Java and Bedrock editions.
Supports Bedrock 1.26 format with NetEase custom extensions.

=== DATA STRUCTURES ===

BedrockBlock struct:
- Name: string (block short name, e.g., "stone")
- DisplayName: string (human-readable, e.g., "Hard Lime Stained Glass")
- ID: int (Bedrock block ID)
- MinStateID: int (minimum state ID for this block)
- MaxStateID: int (maximum state ID for this block)
- DefaultState: int (default state ID)
- JavaName: string (Java namespace, e.g., "minecraft:lime_stained_glass")
- Hardness: float (block hardness)
- Resistance: float (blast resistance)
- Transparent: bool (light passes through)
- Solid: bool (collision enabled)
- Diggable: bool (can be mined)
- EmitLight: int (light emission level)
- FilterLight: int (light filtering level)
- StackSize: int (max stack size)

=== API LOOKUP METHODS ===

GlobalLookup():
- ByJava("minecraft:stone") -> block definition
- ByBedrock("stone") -> block definition  
- ByBedrockStateID(1798) -> "minecraft:stone" (e.g., 1798)
- ByBedrockName("ancient_debris") -> &BedrockBlock{...}
- ByRuntimeID(1) -> block definition (classic format)
- ByNemc("some_ne:custom_block") -> NetEase custom block
- OrByName("minecraft:stone") -> smart lookup (tries all methods)

=== DATA SOURCES ===

- Block properties: Minecraft Wiki

=== JAVA <-> BEDROCK MAPPING ===
Example:
- Java: minecraft:stone -> Bedrock: stone (short name)
- Java: minecraft:netherite_block -> Bedrock state ID: 6158
- Bedrock state ID 11216 -> Java: minecraft:ancient_debris

=== USAGE EXAMPLE ===
import "github.com/Verify144/BlockMap"

blockmap.JavaToBedrock("minecraft:stone") // -> "stone"
blockmap.JavaToBedrockStateID("minecraft:netherite_block") // -> 6158, true
blockmap.ByBedrockStateID(11216) // -> "minecraft:ancient_debris", true
blockmap.ByBedrockName("ancient_debris") // -> &BedrockBlock{...}
