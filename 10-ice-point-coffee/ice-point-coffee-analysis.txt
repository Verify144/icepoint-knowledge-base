=== OVERVIEW ===
AI Building Assistant with:
- Self-written protocol stack (100% original code)
- AI building assistant (multi-turn memory, tool calling, 7 built-in generators)
- Web Dashboard (real-time monitoring, SSE, command panel)
- Performance: 109ns-852ns/op, 300M ops/sec, 0 GC pressure

=== PROTOCOL STACK (100% ORIGINAL) ===

RakNet:
- Frame encapsulation
- Reliability layer
- Flow control
- Packet coalescing / fragmentation

FB Authentication:
- Facebook Auth login flow complete implementation

ECDH Encryption:
- X25519 + P-384 + HKDF + AES-256-CTR
- Key derivation: HKDF-SHA256

MC Protocol (50+ packets):
- Login
- Text
- Command
- Move
- Inventory
- Container
- BossBar
- Skin
- etc.

=== CONFIGURATION ===
~/.icepoint/config.yaml:

# AI config (optional, defaults to Mock AI)
ai:
  base_url: "https://api.openai.com/v1"
  api_key: "your-api-key-here"
  model: "gpt-3.5-turbo"

# Server config
server:
  address: "your-server-code"
  fb_token: "your-fb-token"
  player_name: "IcePoint"

# Database
db:
  path: "~/.icepoint/data.db"

# Plugin config
plugin:
  dir: "./plugins"
  http_port: 8080  # Dashboard port (0 = disabled)
